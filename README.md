# Basic Web 3.0 with Google Colab

This repository contains a beginner-friendly Google Colab notebook that introduces core **Web3** concepts using Python.

## What you'll learn
- How to install and import `web3.py` in Colab.
- How to connect to a public Ethereum RPC endpoint.
- How to read blockchain data (chain ID, latest block number, block details).
- How to check an account balance.

## Open in Colab
1. Upload `basic_web3_colab.ipynb` to Google Drive and open it with Colab, **or**
2. Push this repo to GitHub and open the notebook directly in Colab.

## Notes for beginners
- This notebook uses **read-only** RPC calls, so no wallet/private key is needed.
- You can later extend it to write transactions by using a wallet and private key management best practices.
